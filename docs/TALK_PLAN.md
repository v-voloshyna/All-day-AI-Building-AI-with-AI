**The five limits (closing slide, one line each; on v3 limit 2 is the original one again, which the PDF has):** the reported number is the agent's number · the builder's tests test the builder's beliefs (v2 variant: diligence is a prompt, not a property) · "held-out" was a property of the split, not the data · an optimiser with a free hand optimises the metric · synthetic data has fewer ideas than you think.

**Limit 2, the long form (for Q&A):** in demo 1 the agent was asked to build and report; it reported 94.7 and, unasked, ran a leakage check that found nothing. In demo 2 it was asked to test; it opened the weights and found in two minutes that the number measured spelling. Same model, same data, same agent. What it checks is set by the task, not by what is true, so the number you get is the number for the task you wrote.
